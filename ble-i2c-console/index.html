Packet & connection details ＋

One request at a time. Reads follow writes with a repeated START. Leave write data empty for a read-only transaction, or set read count to 0 for write-only.

Requests are 20 bytes: ID, address, write length, read length, then zero-padded write data. The console removes response headers and padding from the data display.
